Варианты select

Демо для формы категорий

Вариант 1

Нативный select с аккуратной стрелкой

Плюс: почти не требует JS, быстро внедряется.
Минус: раскрытый список браузер рисует по-своему, его нельзя полностью привести к макету.

Вариант 2

Кастомный select в стиле админки

Плюс: можно сделать список ровно таким, как нужен интерфейсу.
Минус: нужно подключить JS-логику выбора и синхронизацию с hidden input.

Вариант 3

Компактный select с поисковой строкой

Плюс: удобно, если разделов станет много.
Минус: для текущих 5-20 значений может быть избыточно.
