# Формулы калькулятора DiTent

Источник: `C:\Users\user\Downloads\Расчет стоимости издел.xlsx`.

Файл содержит текстовое описание формул, а не активные Excel-формулы. Ниже формулы зафиксированы в техническом виде для backend/frontend.

## Общие переменные

- `Rмат` - стоимость материала за 1 м2, берется из `Fabric.price_per_square_meter`.
- `Rсш` - стоимость стачного шва за 1 см, берется из `Formula.seam_price_cm`.
- `Rош` - стоимость отстрочного шва за 1 см, берется из `Formula.topstitch_price_cm`.
- `Rок` - стоимость окантовочного шва за 1 см, берется из `Formula.edging_price_cm`.
- `K` - коэффициент формы, берется из `Formula.coefficient`.
- `W` - ширина рулона ткани, берется из `Fabric.roll_width_cm`; если не задана, используется 148 см.

Итоговая схема расчета:

```text
base = Sмат * Rмат + Lсш * Rсш + Lок * Rок + Z * ((Rсш + Rош) * Lдоп)
price = max(минимальная стоимость, округление вверх до 50(base * K + опции))
```

`Sмат` в коде считается в м2. Формулы из Excel записаны в сантиметрах, поэтому площадь в см2 делится на `10000`.

## Прямоугольная форма

- `A` = ширина
- `B` = глубина
- `C/H` = высота

```text
Sмат = (A * B + 2 * (A + B) * C) / 10000
Lсш = 4 * C + 2 * (A + B)
Lок = 2 * (A + B)
Z = если A <= W или B <= W, то 0, иначе min(3, floor(min(A, B) / W))
Lдоп = A
```

## Круглая форма

- `A/D` = диаметр
- `B/H` = высота

```text
Sмат = (pi * A / 2 * (2 * B + A / 2)) / 10000
Lсш = pi * A + B
Lок = pi * A
Z = если B <= W, то 0; если B > 2 * W, то 3; иначе 2
Lдоп = pi * A
```

## Клиновидная форма

Поля соответствуют схеме `item-img-3.png`:

- `A` = длина
- `B` = меньшая высота
- `C` = глубина
- `D` = большая высота

```text
S = sqrt((D - B)^2 + C^2)
Sмат = ((D + S + B) * A + B * C * 2 + (D - B) * C) / 10000
Lсш = (D + B + S) * 2 + A
Lок = (A + C) * 2
Z = если A <= W или D + S <= W, то 0, иначе 2
Lдоп = A
```

## Овальная форма

- `A` = длина
- `B` = ширина
- `C/H` = высота

```text
P = pi * ((A + B) / 2)
Sмат = (pi * ((A * B) / 2) + P * C) / 10000
Lсш = P + C
Lок = P
Z = если C <= W, то 0; если C > 2 * W, то 3; иначе 2
Lдоп = A
```

Примечание: площадь верхней овальной части перенесена как в Excel: `pi * ((A * B) / 2)`.

## Г-образная форма

Поля соответствуют схеме `item-img-5.png`:

- `A` = задняя длина
- `B` = правая глубина
- `C` = большая высота
- `D` = меньшая высота
- `E` = левая глубина
- `F` = передняя длина
- `G` = внутренняя длина
- `H` = внутренняя глубина

В Excel в площади указан фрагмент `+верх!`. В коде он раскрыт как площадь верхней Г-формы: внешний прямоугольник минус внутренний вырез, то есть `A * B - G * H`.

```text
S = sqrt((C - D)^2 + E^2)
верх = A * B - G * H
Sмат = (0.5 * (C + D) * E + 0.5 * (C + D) * F + (A + B) * C + (G + H) * D + верх) / 10000
Lсш = (C + D + S) * 2 + A + B
Lок = A + B + F + H + G + E
Z = если G <= W или C + S <= W, то 0, иначе 2
Lдоп = C + D + F
```

## П-образная форма

Поля соответствуют схеме `item-img-6.png` и формуле Excel:

- `A` = задняя ширина
- `B` = левая глубина
- `C` = большая высота
- `D` = меньшая высота
- `E` = левая передняя ширина
- `F` = правая передняя ширина
- `G` = внутренняя глубина
- `H` = правая глубина

```text
M = A - E - F
N = H - (B - G)
S1 = sqrt((C - D)^2 + E^2)
S2 = sqrt((C - D)^2 + (B - G)^2)
S3 = sqrt((C - D)^2 + F^2)

Sмат = (
    0.5 * (C + D) * E
    + 0.5 * (C + D) * F
    + (B + A + H) * C
    + (G + M + N) * D
    + ((B + G) / 2) * S1
    + ((A + M) / 2) * S2
    + ((H + N) / 2) * S3
) / 10000

Lсш = C * 2 + D * 4 + S1 + S3 + A + B + H + G + N + M
Lок = E + B + A + H + F + N + M
Z = если G <= W или C + S1 <= W, то 0, иначе 2
Lдоп = C + D + F
```
