# Data model

Основные модели находятся в `shop/models.py`.

## Каталог

- `Category` - разделы и вложенные категории каталога.
- `Product` - готовые изделия из каталога.
- `ProductImage` - галерея изображений товара.

## Справочники конструктора

- `Fabric` - ткани и их характеристики.
- `Color` - цвета/образцы ткани, привязаны к материалу.
- `Fastener` - системы крепления.
- `Formula` - формулы расчета для шести форм чехла.

## Заказы

- `Order` - оформленный заказ пользователя.
- `OrderItem` - позиция заказа: товар из каталога или изделие из конструктора.
- `DrawingOrder` - отдельный сценарий заказа по чертежу.
- `DrawingOrderFile` - файлы, прикрепленные к заказу по чертежу.

## Контент

- `GalleryItem` - элементы галереи.
- `Review` - отзывы.

## Важные ограничения

- Категории имеют уникальный `slug`.
- Товары имеют уникальный `sku`.
- Формулы имеют уникальный `code`.
- Цвет уникален в пределах одной ткани.
- Размеры товаров и формул ограничены диапазоном 10-500 см.
- Характеристики тканей и рейтинг отзывов ограничены диапазоном 1-5.
